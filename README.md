# 44 Vocals (Keywyll) - VST3

Cadena: Gate -> Dynamics (Opto/FET/Opto+FET, Color, De-Ess) -> Tone (EQ + analizador) -> Space (Reverb + Delay con ducking) -> SFX (Pitch Widener, Chorus, Doubler, Lo-Fi Radio, Exciter) -> Output.

## Compilar (Windows, GitHub Actions)
1. Sube esta carpeta a un repositorio de GitHub (incluye .github/workflows/build.yml).
2. Pestaña Actions -> "Build 44 Vocals" -> descarga el artefacto 44-Vocals-VST3.
3. Copia "44 Vocals.vst3" a C:\Program Files\Common Files\VST3 y reescanea en FL Studio.
